# Floppy finish line

Bring the existing Floppy application to a coherent, reliable, polished **internal MVP** without redesigning it from scratch. Floppy should answer where a project is, what is known, what is uncertain, and what should happen next. The active question and decision should dominate the screen.

Completion means a person can create a project with immediate attachments; progress through all 13 Phase 1 chapters with prior context reused; inspect AI proposals and investigate chapter-specific questions; bring back text, files, PDFs, images, links, and notes; see source, synthesis, and confirmed project state separately; and confirm each decision. Project art supports prompt, optional context and references, candidate generation, exact crop and zoom, and explicit approval. Saved work survives refresh and reopening. Normal workspace use avoids document scrolling. Failures are understandable and preserve existing work. Laptop and desktop layouts, keyboard controls, focus, and dialogs work consistently. A fresh user can complete Phase 1 internally without an explanation from the builder.

This goal excludes public production infrastructure, accounts/cloud sync, enterprise permissions, billing, large collaboration systems, and unrelated feature expansion. A successful internal MVP is not a claim that those systems exist.
